## 持续产品要求与人工验收

以下是后续 UI 改动应保留的用户决定，不能仅用测试通过替代视觉判断：

- 笔记本可用视口内呈现主画面、准备配置和核心状态；详情通过页签或弹窗展开。窄／矮窗口合理纵向排列，不强行缩小文字。
- 地理知识与探索趣味通过地图纸色、森林绿、等高线及路线表达；实际状态、下一步操作优先于标语和无用装饰文案。
- 时间使用整分钟；语言和外观采用极简一键按钮，覆盖中英及亮色／暗色／系统。
- 观察、动作依据、执行反馈和核对分别呈现；停止、断连、旧画面和未知状态可辨认。

该版布局与交互已通过人工视觉验收。真实游戏体验和全部物理显示器上的表现仍待验证。


后续记录分别列出：自动检查的版本／矩阵／报告、人工查看的版本／页面／意见，以及真实对局验证（如有）。只改文档不要求再次向用户索取同一版 UI 的视觉认可；涉及布局、主题或主要交互变化时应检查真实渲染并按任务需要安排人工验收。

## 分辨率验收矩阵

2026-11-12，`npm run test:dashboard` 在隔离 Chrome 中交叉验证准备、未载入复盘、运行、结束、已载入复盘五种状态，在中文 / English 与亮色 / 暗色下共 340 个组合。以下尺寸均指浏览器内容区的 **CSS 像素**，不包含系统任务栏或浏览器工具栏；不是物理显示器实测。

| 视口／像素密度 | 布局及验收 |
|---|---|
| 1000×700、1024×768、1280×720 | 小桌面／横向平板：主区域单屏、互不重叠，准备表单无需内部滚动 |
| 1366×650、1366×768、1440×900、1536×864 | 笔记本及常见可用区域：同上；650 高度用于覆盖工具栏占用后的空间 |
| 1920×1080、2560×1440、3840×2160，DPR 1 | 1080p、2K、4K 大视口：同上 |
| 1920×1080，DPR 2 | HiDPI 渲染：同一 CSS 布局，输出为 3840×2160 像素；不等同于浏览器缩放测试 |
| 999×768、768×1024、390×844、320×740 | 窄窗口／移动尺寸：纵向重排，无横向溢出，控件不横向裁切 |
| 1280×600、853×480 | 高度受限窗口：纵向重排，不为强行单屏而继续缩小文字 |

所有组合均检查页面横向溢出和按钮／输入控件的横向裁切。长观察、事件与日志允许在各自面板内滚动。报告 `artifacts/ui-acceptance/<时间>/acceptance.json` 的 `layoutChecks` 逐项记录状态、视口、DPR、语言、主题和布局类型；关键尺寸另有模拟截图。每次检查使用独立时间目录，避免覆盖此前证据；旧版直接写在 `ui-acceptance/` 下的报告仅作历史记录。桌面缩放、浏览器缩放和不同字体环境可能改变实际可用 CSS 视口，不能仅凭显示器标称分辨率保证相同布局。

## 分钟、语言与外观验收

- 默认输入为 5 / 30 分钟，原生步进每次 1 分钟；小数、零、负数和不安全整数被拒绝。模拟启动核对请求仍为 300 / 1800 秒。
- 双语覆盖静态控件、状态、事件标签、提示和复盘摘要；原始观察、理由、日志和外部诊断保留原文。模板测试确保插值不重复解释原文中的花括号。
- 切换语言与主题后保留配置、授权勾选、回放位置和观察内容。语言切换不暂停回放，也不修改原始文件。
- 语言与主题使用原生按钮一键切换，无下拉菜单；语言支持空格键，外观支持 Enter 键，图标、悬停提示与辅助技术标签反映当前模式及下一操作。
- 系统外观从亮到暗及从暗到亮实时更新；显式亮色不受系统变化影响。偏好刷新后保留；损坏或不可用的存储不阻止页面运行。
- 两种主题分别检查主要文字配色对比度，目录选择使用界面自己的双语按钮；原生文件对话框本身仍使用浏览器／操作系统的语言。

## 回归命令

2026-11-12 全项目审查补充：回放关闭后清空画面、观察、用量和原始日志，空白复盘页不沿用实时信息；已开始但没有结束记录的调用计入未知用量。相应单元测试及隔离 Chrome 交互检查覆盖这些行为。本轮未改变布局或主题，自动布局结果不构成新的用户视觉验收或真实游戏验证。

- `npm test`：离线单元与本机接口回归。应在允许回环连接的正常用户环境执行，确认零跳过。
- `npm run test:preview`：两个隔离 Chrome，验证模拟页面变化进入预览、控制台启动/停止、目录回放及浏览器退出。
- `npm run test:dashboard`：隔离 Chrome 中的完整 UI 验收，生成 `artifacts/ui-acceptance/` 下的模拟截图与 `acceptance.json`。
- `npm run test:clean`：不含 `.git`、`artifacts/`、`node_modules/` 的临时副本执行离线测试与 CLI 帮助。

## 证据边界

- 以上检查不证明真实页面、模型表现、费用或真实游戏停止链路已验证。
- 预算为近似值；预览可读不代表网站模式、计时或模型登录已核实。
- 图钉核对不是定位正确率；不生成内部推理或未经校准的置信度。
- 在线完整日志为载入时快照，上限 32 MiB；更大记录通过本地目录复盘读取。
- 可访问性检查覆盖本次主要文字配色、原生控件键盘入口与状态语义，不是完整 WCAG 认证或屏幕阅读器实测。
- 模拟截图仅保存在忽略的 `artifacts/`，不纳入提交和推送；未增加真实运行素材。

## 控制台行为参考

以下细节从 README 移至此处维护；首页保留使用入口与当前验证摘要。

控制台时限以**分钟**输入，默认单题 5 分钟、单局 30 分钟，最小值和步长均为 1 分钟；发送请求时转换成秒，CLI 的 `--round-seconds` / `--total-seconds` 参数仍以秒为单位。右上角语言按钮一键切换中文 / English；外观图标按钮按亮色 → 暗色 → 跟随系统循环切换，悬停可查看当前模式与下一模式；系统模式会实时响应系统外观变化。偏好保存在当前浏览器、当前控制台地址的本地存储中，刷新后保留；更换端口或浏览器后可能恢复默认。切换语言和主题不改变运行配置、确认勾选或回放位置；模型原文、原始日志和外部诊断信息保留原语言，不调用翻译服务。

控制台采用地图纸色、森林绿、等高线与五题路线的探索主题。准备页显示下一步操作，以及服务连接、预览、网页人工核对和运行授权四项检查。在已验收的桌面视口中，准备表单、主画面与核心状态保持单屏；右侧切换观察手记、事件和每题摘要，完整日志与操作预算通过弹窗查看。较长的事件和观察在侧栏内部滚动，宽度不足 1000 或高度不足 640 CSS 像素的窗口改为纵向排列。未开局插画仅为探索示意，不是真实地图或当前题目线索。

控制台也可选择包含一份 `events.jsonl` 和对应截图的本地运行目录进行离线回放；多份日志的目录会被拒绝，截图缺失时会隐藏旧画面并提示。所选文件仅由浏览器读取；现有运行目录可能含用户信息和未审查素材，不能直接公开。回放载入后先暂停，可按局、题或关键事件跳转，也可播放、暂停和拖动进度；默认每秒处理约 8 个事件，选择器直接标注“事件/秒”，不代表原始实时速度。每题摘要依据整份日志，画面与动态则对应选中的事件。跨题清除旧截图；同题事件没有新截图时显示最近截图及其原始事件编号。日志末尾未写完时会保留此前事件并提示截断。公开的脱敏样例和视频尚未制作。

回放目录可选放置 `replay-meta.json`，例如 `{"schema_version":1,"source":"simulated","editing":"none"}`；`source` 可为 `real` 或 `simulated`，`editing` 可为 `redacted`、`none` 或 `unknown`，可选的 `recorded_at` 使用带时区的 ISO 8601 时间。界面会把这些内容标为“文件声明”；程序不会验证声明或自动完成脱敏。不提供该文件时，来源与编辑情况显示为未知。

控制台的启动区分别展示程序可检查的预览状态，以及需要用户核对的网页模式、计时和真实运行范围。修改模式或预算后须重新勾选确认；只有服务连接和预览均较新时才允许启动。预览可读不代表模型已登录、模式正确或网站计时匹配。三种模式均有操作边界说明，操作上限放在高级设置中，每局预算独立重置。

运行观察将模型实际返回的线索、动作依据、执行结果和图钉核对分开展示；不补写内部推理或推测置信度。断连时预算显示未知，明确连接中断不等于 Agent 停止；预览失败时标注旧画面与最近更新时间。停止失败可重试，等待进程结束期间保持“正在停止”，已发出操作和远端模型状态仍可能未知。移动变化未确认、兜底原因与核对不确定会保留为独立状态。

右上角“探索记录”默认显示最近 120 行输出，可按需载入本次运行的完整事件日志快照；读取仅限本项目当前运行目录，不接受任意文件路径。超过 32 MiB 的日志需通过本地目录复盘查看。回放只读浏览器中的文件，保留来源声明、缺失结果、未结束调用和混合用量口径；每题用量按本题口径显示，跨题总量口径混合时不合计。模型与推理强度未知的原因收在运行详情中，不据此估算费用。

## 2026-11-12 长日志回放维护

摘要采用增量归约和有限数量的跳转检查点，按局／题导航预先索引。关键事件窗口显示当前位置附近最多 120 项；拖动进度仍可访问完整事件序列。探索记录弹窗打开时才生成当前位置之前最多 120 条预览，每条最多 4000 字符，超长项以省略号结束。原始观察和统计不因预览限长而修改；“另存完整原始日志”使用用户选择的原文件，保留 BOM、空行和未完成尾行。切换或关闭记录时释放旧下载地址。

合成验收增加 50,000 事件的随机跳转、回退、时间线节点上限、关闭日志时零 DOM 更新、原文件逐字节下载及中英文提示。浏览器加载／跳转耗时写入该次验收目录的 `replay-performance.json`，包含 CDP 测试开销。已有 340 组合仍检查；本次没有新增人工视觉验收、真实游戏或模型测试。
