# 项目决策记录

整理日期：2026-11-12（北京时间）。本文件记录已确认的长期产品选择，不是运行或发布授权，也不证明某项功能已经验证。当前能力及限制以 [README](../README.md) 为入口，协作规则见 [AGENTS](../AGENTS.md)。

新决定替代旧决定时，更新对应条目并保留替代关系；不复制完整聊天、个人信息、一次运行授权或临时地址。

| 编号 | 当前决定与原因 | 适用范围及替代关系 |
|---|---|---|
| D01 | 以视觉 Agent 与 Harness 工程能力为核心，展示可靠执行、可观察性和复盘能力 | 面向开发者、求职作品读者及图寻社区；分数是实验结果，暂不做模型排名或复杂 benchmark |
| D02 | 保留真实游戏能力，面向题库板块各题库的经典五题，支持固定、移动和固定视角 | 替代早期每日挑战目标及特定题库名称限制；目标兼容范围不代表全部题库已经实测 |
| D03 | 文档表达禁止用于每日挑战、匹配等竞技板块的立场，使用者负责遵守适用规则 | 不额外恢复已否决的题库白名单；保留可见页面、模式、动作目标检查以避免误操作，不承诺技术上阻止一切二次开发滥用 |
| D04 | 专用 Chrome 接口操作，不接管桌面；用户负责登录，默认人工首次开局 | 明确授权范围内可自动重开或切换模式；替代“每次重开都必须重新人工确认”的绝对表述，不产生无限运行许可 |
| D05 | 正常运行在预算内优先给出结果，允许明确标注的兜底；停止和硬性故障保护优先 | 替代早期核对不通过即一律停止的策略；“每题尽量提交”不承诺浏览器失联、预算耗尽或停止后仍能提交 |
| D06 | 每题时间与操作额度在每题重置，每局时限在新局重置，局数独立设置 | 替代多局共享总时限的旧解释。CLI 的 `--total-seconds` 仍表示每局秒数；控制台用整分钟输入。重启同一题不自动续满预算 |
| D07 | 本地 Web 控制台是推荐体验入口，保留 CLI，复用运行与预算逻辑 | 替代早期仅终端、不新增 GUI 的阶段性范围；Windows、Node.js、Chrome、Codex CLI 为当前技术路线，多后端与跨平台留待后续 |
| D08 | 展示模型实际返回的观察、动作理由和执行结果，核对与定位正确性分开 | 不生成内部推理或未经校准的置信度；缺失结果、用量及有效模型配置保留未知 |
| D09 | 记录 token 及能可靠确认的实际模型与推理强度，不计算或记录费用 | 替代早期费用展示设想；配置请求不等于实际生效值，缓存口径与缺失调用必须说明，token 不是可保证的硬费用上限 |
| D10 | 真实演示使用新版 UI 下新录制的图寻游戏，产出 MP4、README 短 GIF 和脱敏离线回放 | 替代模拟画面作为正式真实演示及优先使用旧 UI 素材的建议；模拟仍服务自动测试，录制和公开各按任务授权执行 |
| D11 | 中文 README 是维护主入口，英文是精简准确的介绍；UI 提供中英和亮色／暗色／系统切换 | 后续 UI 要求替代早期“不承诺双语界面”。语言和外观用极简按钮，偏好切换不影响运行或回放 |
| D12 | 笔记本可用视口内显示主画面、配置与核心状态，地理探索视觉配合实际状态和下一步操作 | 用实用信息替代标语和无用提示；详情按需展开，高度或宽度不足时允许纵向排列，不为单屏牺牲可读性。具体矩阵见 UI 验收清单 |
| D13 | MIT 代码许可配合社区立场；私有开发与公开发布分别同步 | 不把一个本地仓库的双远程理解为镜像推送。公开内容、素材和可达历史须审查；独立公开历史是现有发布方案，实际发布仍需授权 |

相关验收：[UI/UX 清单](../test/UI_UX_ACCEPTANCE.md)、[开发和证据规范](../CONTRIBUTING.md)。
